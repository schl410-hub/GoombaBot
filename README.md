# 굼바봇 (GoombaBot)

## 사용 방법 (한 번만 설정하면 이후 자동 업데이트됩니다)

### 최초 1회 설정

1. `loader.js` 파일을 받는다
2. 메신저봇R 앱 → 굼바봇 스크립트 편집 화면을 연다
3. 기존 내용을 전부 지우고, `loader.js` 내용 전체를 붙여넣는다
4. 저장/컴파일 버튼을 누른다
5. `main.js.b64` 파일을 GitHub 저장소(schl410-hub/GoombaBot)의 `main.js.b64`라는
   이름 파일로 올린다 (이미 있다면 내용을 통째로 교체)

**이후로는 메신저봇R 화면을 다시 열 일이 없습니다.**

### 앞으로 업데이트할 때 (매번 이렇게만 하면 됩니다)

1. Claude에게 새 기능/수정 요청 → 새 `main.js.b64` 파일을 받는다
2. GitHub에서 `main.js.b64` 파일 내용을 그 새 파일 내용으로 통째로 교체하고 저장
3. 카카오톡 길드방에서 `!굼바봇 업데이트` 라고 친다
4. 끝 — 메신저봇R을 다시 열 필요도, 코드를 이해할 필요도 없습니다

## 개발용 구조 (Claude 참고용)

```
src/                # 실제 코드 (기능별로 파일 분리)
main.js             # src/를 빌드한 결과물 (사람이 읽을 수 있는 형태)
main.js.b64         # main.js를 GitHub에 올리기 위해 안전하게 변환한 파일
                    # (GitHub에는 이 파일만 올리면 됨 - main.js는 안 올려도 됨)
loader.js           # 메신저봇R에 딱 한 번만 붙여넣는 파일
```

```
npm install
npm run build   # src/ -> main.js, main.js.b64 둘 다 자동 생성
```
